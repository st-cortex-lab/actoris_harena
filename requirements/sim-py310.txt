# The simulated arenas' environment, fully pinned: what `pip install -e ".[sim,torch]"`
# resolved to on 2026-11-08 at the newest versions that still hold numpy<2, gym 0.26
# and Python 3.10 (pyflex, softgym's simulator, is built for cp310 only). Every
# method repository's file in this directory builds on it, and the smoke runs in
# README.md, section 8, pass against exactly these versions.
#
#   conda create -n harena-sim python=3.10 -y && conda activate harena-sim
#   pip install -r requirements/sim-py310.txt
#   pip install -e . --no-deps
#
# Ceilings, and why:
#   torch 2.12.1  -- the newest torch PyG builds cp310 wheels for (the VCD
#                    baseline needs them; see magpie.txt). 2.13/2.14 have cp310
#                    torch but no PyG, and 2.15 drops Python 3.10.
#   torchaudio    -- not installed: nothing imports it, and its last release
#                    (2.11) would hold torch back.
#   opencv 4.11   -- 4.12 requires numpy 2.
#   open3d 0.18   -- 0.19+ ships only glibc>=2.31 wheels, so it will not install on
#                    an EL8 cluster (Viking: Rocky 8, glibc 2.28).
# cu126 wheels run on any driver >= 525 (CUDA minor-version compatibility).
